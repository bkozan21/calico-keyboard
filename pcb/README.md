# PCB
This directory contains KiCad files for the Calico keyboard. The file names are called ergogen_output because the layout was generated using ergogen. However, the pcb design contains some updates. Of course, I added traces. In addition, I added some extra footprints and some silkscreen text.

## Custom Design Rules
I used custom design rules made specifically for JLCPCB. I got those custom design rules from https://github.com/Cimos/kicad-druid/tree/main.

The file I used: https://github.com/Cimos/kicad-druid/blob/main/JLCPCB/JLCPCB-2L-1oz.kicad_dru

## Gerber files
The gerber files I used to order the PCB can be found in the gerber_files directory.
